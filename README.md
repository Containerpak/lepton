# Lepton (cpak)

Lepton is packaged as an optional compatibility tool for Steam, with the podman runtime it needs.

```bash
cpak addon enable github.com/containerpak/steam github.com/containerpak/lepton
```

Restart Steam after enabling or disabling a compatibility tool. The Android system images are distributed by Steam with the Lepton tool (app 3029110); `lepton` uses them when Steam has installed them.
